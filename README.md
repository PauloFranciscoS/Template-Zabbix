# Templates Zabbix 📊

Este repositório é uma coleção de templates para Zabbix que desenvolvi e adaptei para monitoramento avançado de ativos de infraestrutura. Todos foram criados com foco em ambientes Enterprise (produção).

## 🗂️ Catálogo de Templates

Abaixo você encontra a lista de equipamentos homologados. Clique no link para acessar os arquivos do template e as instruções específicas de instalação de cada um.

| Tecnologia / Equipamento | Versão Zabbix | Descrição Principal | Link do Template |
| :--- | :---: | :--- | :--- |
| **Nobreak (Padrão UPS-MIB)** | 7.0+ | Monitoramento SNMP focado em saúde da bateria, tensões elétricas, detector de queda de energia e rede. | [Acessar Pasta](./Nobreak-UPS-MIB) |
| **Servidor Dell R710 (iDRAC)** | 7.4+ | Monitoramento híbrido (SNMP, SSH, ExternalScripts) de hardware, inventário, temperatura e consumo elétrico (kWh/W). | [Acessar Pasta](./Dell-PowerEdge-R710) |
